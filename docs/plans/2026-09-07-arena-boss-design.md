# Arena boss event: Świadek — design

> Renamed the same night: HeezQ found the courtroom angle (a witness who
> testifies) cringe. The boss is now **Obserwator** — the watcher from the edge
> of render distance — and every player-facing line was rewritten around
> "it watches, it never blinks, close its eye". Internal ids (`witness`,
> `witness_eye`) stayed.

Written 2026-09-07. HeezQ asked for a periodic server event: a chat line saying
a boss has appeared on an arena, a clickable part that teleports the player to
that arena (its own dimension, built by the mod), a polished boss with a real
model, effects and interesting mechanics, moderately hard, joinable by the
whole server at once, with custom status effects and a "dopamine booster"
feel. HeezQ is not available for questions; every choice below states its
assumption.

## Who the boss is

**Świadek** ("The Witness") — *ten, który widział wszystko*. The motionless
figure Paranoia shows at render distance was never a pillager; it wore the
shape. It has seen every grow, every sale, every address in town, and it is
going to testify. Everyone on the server has a reason to shut it up, which is
what makes a server-wide event read as a server-wide event rather than a
random dragon. It carries the black cases — the Phantom tier that nothing on
the shelf sells — which is where those come from now.

Assumption: a boss tied to existing lore (Paranoia's watcher, the case tiers,
dirty money, the laundry) beats a generic fantasy boss on a server whose
whole identity is the trap house. The look is a shadow: a tall hooded shape
with a single huge eye, floating hands, a crown of shards, six small eyes
orbiting it. Purple, cyan and gold — the mod's own palette.

## Architecture

Server-side, on Polymer, like everything else in the mod:

- **The dimension** `trapcraft:arena` is a datapack dimension shipped in the
  jar (`data/trapcraft/dimension_type/arena.json`, `dimension/arena.json`,
  both generated by `gen_assets.py`). Flat void generator, `the_void` biome
  (no spawns, no rain), fixed time midnight under overworld sky effects so
  there are stars and a full moon. Added to the existing world by the
  registry loader; the folder appears under `world/dimensions/trapcraft/arena`
  on first use.
- **The arena** is a blueprint: `tools/gen_arena.py` writes
  `data/trapcraft/arena/arena.blocks.gz` (one line per block:
  `x y z blockstate [tag]`) and a preview PNG on the desk. `ArenaBlueprint`
  parses it with `BlockArgumentParser` and places it at (0, 64, 0) every time
  an event starts, so the pit self-heals. Tagged positions (`vein`, `glow`,
  `sigil`) give the fight its light switches.
- **The boss** is a real `HostileEntity` (`WitnessEntity`) so swords, arrows,
  crits, enchantments and knockback all work as in vanilla. It implements
  `PolymerEntity` disguised as a **pillager** (the shape the watcher wore),
  scaled ×1.7 through the `SCALE` attribute so the client's hitbox matches the
  server's, and set invisible. `PolymerEntityUtils.registerType` keeps the
  custom type out of the registry sync.
- **The model** is a Polymer virtual-entity rig (`WitnessRig`): an
  `ElementHolder` of `ItemDisplayElement`s attached with
  `EntityAttachment.ofTicking`, each showing a generated 3D item model through
  an `item_model` component on a paper stack — no items registered for the
  parts. Eyes use `Brightness.FULL` so they glow in the dark; the body carries
  the shadow. Parts are laid out from a generated `data/trapcraft/arena/rig.json`
  so a desk previewer and the server read the same numbers. Animation is
  per-tick transforms with 2-tick interpolation.
- **Orbs** (`WitnessEyeEntity`) are plain entities disguised as
  `interaction` entities (hittable boxes) with a display rig attached, so a
  player can punch one back at the boss.
- **Mirror copies** are holders anchored to the chunk with an
  `InteractionElement` that shatters on attack. No entity behind them.
- **Effects**: two real status effects, `Groza` (dread, the boss's debuff) and
  `Adrenalina` (the reward buff), plain `StatusEffect`s with generated icons,
  never `PolymerStatusEffect` (its default replacement strips the effect from
  the sync — see `BakedStatusEffect`).
- **Client extras** (optional module, everyone has it via the pack): a
  `TrapNet.Shake` payload for camera shake and a `TrapNet.Flash` for a screen
  flash, handled in `client/ArenaLook`. Without the client half the fight is
  identical minus the shake.
- **Economy**: bounty emeralds enter the world through `TrapMarket.pay`
  (money entering the world — the only correct pair). Cases come from the
  boss; the *keys* stay on the shelf, so every event creates demand for a
  22,000e key — a sink, not a printer. Dirty emeralds are an item the market
  never counted and are laundered through the existing drum.

## The event

```
IDLE ── roll ──> GATHERING (2 min) ──> FIGHT (≤10 min) ──> VICTORY (fireworks, loot, 90 s) ──> IDLE
                                       │                                                ▲
                                       └── enrage / nobody came / /arena stop ── DEFEAT ┘
```

- **Roll**: every 20 min of real time, with ≥2 players online and ≥90 min
  since the last event ended, a 14% roll. Expected ~1 event per 2.4 h of
  eligible time. Persisted in `world/trapcraft-arena.txt` so a restart does
  not re-roll instantly. Ops can `/arena start [seconds]` at any time.
- **Announcement**: broadcast to everyone, styled, with a clickable
  `[ WCHODZĘ ]` that runs `/arena join`, plus a raid-horn sound for all and a
  global boss bar counting down. Repeats at 60 s and 15 s. The link keeps
  working for the whole fight (late joiners land at the gate).
- **Join**: the player's world + position + look are stored (per UUID,
  persisted), they are teleported to the gate landing facing the pit. `/arena
  leave` returns them at any time. Disconnecting mid-event: on next login,
  anyone in the arena world with no event running is sent to their stored
  origin, or the overworld spawn.
- **Intro** (5 s): the sigil lights, the ground shakes, the boss rises out
  of the floor with reverse-portal swirl and a wither-spawn roar; title
  `ŚWIADEK` / `Widział wszystko. Zeznaje dziś.` Boss bar with dragon music
  for players in the arena; a plain spectator bar for everyone else online
  so the whole server sees the HP go down.
- **Nobody came** by the end of gathering: `Nikt nie przyszedł.` and the
  cooldown starts.
- **Knockout**, not death: `ALLOW_DEATH` cancels a player's death in the
  arena; they keep their inventory, are healed and moved to the stands for
  20 s, and the boss heals 8% of max (visible on the bar, with a taunt).
  While knocked out their damage on the boss is ignored, so jumping back in
  early buys nothing. Void below y=40 teleports to the gate.
- **Enrage** at 10 min: `Świadek zeznał.` — it vanishes, no loot, cooldown.
- **Victory**: 4 s death animation, an 8 s firework show around the pit,
  loot, a damage leaderboard in chat, `Adrenalina` for 3 min, a `[ WRACAM ]`
  link, and auto-return 90 s later.

## The fight

Health `400 + 220 × (players − 1)`, any single hit capped at 6% of max
(modded weapons on this pack hit for absurd numbers), armour 4, knockback
resistance 1, immune to status effects. Melee 8. Three phases at 66% and 33%,
each transition a 3 s invulnerable flourish that gives everyone in the pit
`Adrenalina` 20 s and a heal.

| Ability | Phase | Cadence | Telegraph | Counter |
|---|---|---|---|---|
| **Fala** (shockwave) | 1+ | 12 s | rises 1.2 blocks, anchor-charge sound | be airborne when the ring passes — jump it |
| **Oczy** (homing orbs) | 1+ | 9 s | eye flash, shulker shoot | punch an orb: it flies back and hits the boss for 25, `ODBITE!` |
| **Spojrzenie** (the stare) | 2+ | 20 s | eyes go red, `NIE PATRZ` title, shrieker | look away for 3 s; looking costs 3 per half second and a Groza stack, with the elder-guardian face |
| **Piorun** (lightning marks) | 2+ | 15 s | yellow dust circles for 1.5 s | step out of the circle |
| **Lustra** (mirrors) | 2 start, then 40 s | — | illusioner mirror sound | the copies shatter on a hit; only the real one has orbiting eyes |
| **Skok** (blink) | 3 | 8 s | enderman sound, collapse and re-expand | none — it is repositioning; the lights are off by now |
| **Uścisk** (grip) | 3 | 22 s | phantom swoop, chain rattle | the others deal `12 × players` damage within 5 s or the held player eats 10; a mini bar shows the count |

`Groza` (dread) is the boss's currency: melee, orbs and the stare add a stack
(amplifier 0–3, 15 s, refreshed). Stacks slow you (−8% each), at 2 the screen
pulses darkness, at 3 you bleed 1 every two seconds with a heartbeat. **It
decays while another player stands within 4 blocks** — the same company rule
Paranoia uses, so grouping up is the counter and the mechanic teaches itself.

`Adrenalina`: +15% speed, +2 attack damage, 1 HP per two seconds, crit
sparks. 20 s on every phase break, 3 min on the kill — you walk out of the
arena buffed.

Phase 3 turns the pit's sea-lantern veins and wall glow off (real block swaps,
put back on rebuild); only the pillar soul-fires and the boss's own light
remain.

## Rewards

Everyone who dealt damage:

- a share of the bounty, `2500 + 1200 × players` emeralds, split by damage
  with a 15% floor per person, paid via `TrapMarket.pay`;
- one **Skrzynka Widmo** straight to the inventory (needs the 22,000e key
  from the shelf — the sink);
- `Adrenalina` 3 min, ~1200 XP in orbs.

Top damage additionally: one **Klucz Widmo** and the trophy **Oko Świadka**
— a 3D eye item; right-click and every creature within 40 blocks glows for
you alone for 8 s (per-player flag packets, TrapPhantom-style), 90 s
cooldown. The shop refuses to buy it (`TrapScrap`). Boss-drop only, which is
"reachable" because the event is open to everyone.

A loot fountain at the death spot: `12 + 6 × players` dirty-emerald blocks
launched in an arc — whoever grabs them launders them.

Advancements (impossible-trigger, granted from code): `witness` (be there
when it falls), `parry` (reflect an orb), `stare` (survive a stare without
looking), `unbroken` (win with no knockouts).

## Commands

`/arena join`, `/arena leave` for everyone. Ops: `/arena start [seconds]`,
`/arena stop`, `/arena tp`, `/arena build`, `/arena cast <ability>` — the
debug command ships with the feature because a one-in-a-few-hours event is
otherwise untestable.

## Files

Java: `ArenaMath` (pure formulas, tested), `TrapArena` (event, commands,
bars, loot, persistence), `ArenaBlueprint`, `WitnessEntity`, `WitnessRig`,
`WitnessEyeEntity`, `DreadStatusEffect`, `AdrenalineStatusEffect`,
`WitnessEyeItem`, `client/ArenaLook`. Wiring in `TrapCraft`, `TrapContent`,
`TrapNet`, `TrapCraftClient`, `TrapGuide` (`/guide arena`), `TrapScrap`.
Generators: `gen_textures.py`, `gen_assets.py`, new `gen_arena.py`,
`gen_wiki.py`. Test: `ArenaMathTest`.

## Not doing

- No GeckoLib model: it would tie the boss to the client half, and a
  display rig can be previewed on the desk.
- No custom `.ogg` sounds: vanilla has warden, wither, illusioner, sculk
  and firework layers enough; layering them is free and cannot break.
- No permadeath or item loss in the arena: the event is meant to be joined,
  not feared.
- No second boss. One, done properly.
